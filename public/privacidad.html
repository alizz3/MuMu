Política de privacidad de MuMu 🐮

Última actualización: 7 de octubre de 2026

MuMu es una aplicación de organización personal creada y usada por Aliz Mejía. No es un servicio público: solo las cuentas autorizadas por su dueña pueden usar el servidor.

Qué datos se usan

  • Cuenta de Google (inicio de sesión): nombre, correo y foto, para identificarte.
  • Gmail (solo lectura, opcional): remitente, asunto, fragmento y fecha de correos recientes, para detectar los importantes. No se envían, borran ni modifican correos.
  • Google Calendar (opcional): tus eventos, para calcular tiempo libre. Solo se crean eventos si das ese permiso aparte.
  • Google Classroom (solo lectura, opcional): cursos y tareas asignadas.
  • Tu Aula / Moodle (opcional): actividades, fechas y avisos de tus cursos. La contraseña no se guarda; solo un token cifrado.
  • Datos que escribes: tareas, hábitos, notas, registros de sueño y demás contenido de la app.

Dónde se guardan

En una base de datos privada de Firebase (Google Cloud) a la que solo accede tu cuenta. Los tokens de Google y de Tu Aula se guardan cifrados (AES-256) en una zona que el navegador no puede leer.

Con quién se comparten

Con nadie. Los datos no se venden ni se usan para publicidad. Si activas el asistente con IA, el resumen de tu día se envía a la API de Anthropic solo para generar la respuesta.

Uso de datos de Google

El uso de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo borrar tus datos

Desde Configuración puedes desconectar cada cuenta (eso revoca el acceso en Google) y borrar los datos de ejemplo. También puedes quitar el acceso en myaccount.google.com/permissions.

Tus derechos

Según la Ley 1581 de 2012 de Colombia (habeas data) puedes conocer, actualizar, rectificar y pedir que se eliminen tus datos, y revocar la autorización en cualquier momento escribiendo al correo de contacto.
